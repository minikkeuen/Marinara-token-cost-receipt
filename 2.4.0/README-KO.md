# Token Cost Receipt for Marinara Engine 2.4.0

현재 채팅의 최신 AI 응답에 저장된 토큰 사용량을 읽어 예상 비용을 표시합니다. 공급자와 모델별 단가 프리셋, 캐시 읽기·쓰기 과금 방식, USD/KRW 환율을 저장할 수 있습니다.

화면의 🧾 버튼을 클릭하면 영수증 패널이 열리고, 다시 클릭하거나 패널의 `×` 또는 Escape 키로 닫힙니다. 버튼은 드래그해 옮길 수 있으며 위치가 저장됩니다.

## v2 단가 프리셋

- OpenAI GPT-5.4·5.5·5.6 계열과 GPT-5.4 mini/nano
- Claude Fable 5, Opus 5, Sonnet 5, Opus 4.6·4.7·4.8 및 Sonnet 4.6
- Gemini 3.1·3.5·3.6 계열
- DeepSeek V4, GLM-5, Kimi K2.6·K3

프리셋의 `값 불러오기`는 입력란만 채웁니다. 기존 설정은 `저장·재계산`을 눌렀을 때 변경됩니다. Gemini 캐시 스토리지 비용은 사용량에 보관 시간이 기록되지 않으므로 계산하지 않습니다.

Claude 프리셋은 캐시 쓰기 TTL을 5분 또는 1시간으로 선택할 수 있습니다. 이 선택은 영수증의 캐시 쓰기 단가를 바꾸는 기능입니다. 실제 API 캐시 TTL은 Marinara의 Anthropic 연결 편집에서 `프롬프트 캐싱`과 `확장 토큰 캐싱(1시간)`을 설정해야 합니다. Sonnet 5는 2026년 9월 1일 가격 변경을 구분할 수 있도록 변경 전·후 프리셋을 각각 제공합니다.

OpenAI GPT-5.4·5.5·5.6 대상 모델은 전체 입력이 272,000토큰을 초과하면 입력·캐시 입력을 2배, 출력을 1.5배로 계산합니다. Gemini 3.1 Pro는 전체 입력이 200,000토큰을 초과하면 입력·캐시 입력을 2배, 출력을 1.5배로 계산합니다. 장문 구간이 적용되면 영수증에 기준과 실제 입력 토큰을 표시합니다.

## 필요한 권한

이 확장은 현재 채팅 메시지의 토큰 사용량을 읽고 화면에 영수증을 표시해야 하므로 `full_page_access`를 사용합니다. 코드는 Marinara 페이지에서 실행되며 다음 작업을 수행합니다.

- 같은 출처의 `/api/chats` 및 채팅 메시지 조회
- 환율 갱신을 위한 `https://api.frankfurter.dev` 요청
- 확장 전용 저장소에 단가, 환율, 창 위치 저장
- 영수증 화면과 관리형 타이머 등록

## 기존 확장 교체

Marinara Engine 2.4.0의 External Extensions에서 기존 **Token Cost Receipt**를 열고 `extension.js`로 저장 코드를 교체합니다. 교체 직후 확장은 비활성화되며 새 코드 해시 승인이 필요합니다. 동일한 확장 항목을 교체하면 기존 전용 저장소의 단가 설정을 이어서 사용합니다.

처음 설치하는 경우 이 폴더 또는 배포 ZIP을 가져온 뒤 요청 권한과 코드를 검토하고 승인합니다.
