# Token Cost Receipt for Marinara Engine 2.4.1

현재 채팅의 최신 AI 응답에 저장된 토큰 사용량을 읽어 예상 비용을 표시합니다.

## v2.0.1 네트워크 사용량 수정

여러 채팅의 메시지를 2.5초마다 반복 조회하던 동작을 제거했습니다. 이제 영수증 패널을 열 때, 패널이 열린 상태에서 현재 채팅의 생성이 완료될 때, 다른 채팅으로 이동할 때 또는 사용자가 새로고침 버튼을 누를 때만 활성 채팅 한 개의 최근 20개 메시지를 한 번 조회합니다. 패널이 닫혀 있거나 열린 채로 대기 중일 때는 메시지를 조회하지 않습니다.

2.4-test의 개인 확장 API와 기존 확장 저장소를 그대로 사용하므로 저장된 단가·환율·버튼 위치 설정은 유지됩니다.
