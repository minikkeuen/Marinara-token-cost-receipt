# Token Cost Receipt for Marinara Engine 2.4.1

각 AI 메시지의 하단 도구줄에 영수증 아이콘을 추가하고, 선택한 메시지 한 건의 예상 비용을 표시합니다.

## v3.0.0 메시지별 영수증

- RP 모드는 화면에 표시된 모델·입력·출력·캐시 토큰 정보를 우선 사용합니다. 이 방식은 추가 네트워크 요청이 없습니다.
- RP 화면 정보가 없을 때 `Peek Prompt`를 보완 조회할지는 설정에서 선택할 수 있으며 기본값은 꺼짐입니다.
- 대화모드는 화면에 토큰 정보가 표시되지 않으므로, 영수증 아이콘을 누른 메시지 ID로 `Peek Prompt`를 한 번 호출합니다. 기본값은 켜짐입니다.
- `Peek Prompt`는 AI 제공자에게 새 요청을 보내지 않지만 Marinara 서버에서 브라우저로 저장된 전체 프롬프트 응답을 내려받습니다.
- 백그라운드 조회, 채팅 순회, 포커스 복귀 조회, 메시지 주기 타이머는 없습니다.
- 환율은 저장된 값을 사용하며 사용자가 영수증 설정에서 수동 갱신할 때만 외부 요청을 보냅니다.

기존 2.x의 모델별 단가·환율 설정은 같은 확장 저장소에서 이어서 사용합니다. RP 화면 파싱을 사용하려면 Marinara의 모델명 및 토큰 사용량 표시가 켜져 있어야 합니다.

## 조회 방식 기본값

- RP 화면 정보: 켬
- RP Peek Prompt 보완: 끔
- 대화모드 Peek Prompt: 켬

각 메시지의 영수증 팝오버에서 톱니바퀴 버튼을 누르면 위 설정을 변경할 수 있습니다.
