# Token Cost Receipt for Marinara Engine 2.4.1

각 AI 메시지의 하단 도구줄에 영수증 아이콘을 추가하고, 선택한 메시지 한 건의 예상 비용을 표시합니다.

## v3.0.5 변경 사항

- 현재 채팅의 `/api/chats/{chatId}/messages`에서 메시지 `createdAt`을 읽어 `messageId → createdAt`으로 짧게 캐시합니다.
- RP 모드의 기존 시간 표시를 `MM.DD 오전/오후 HH:MM` 형식으로 보강합니다. Conversation 모드 표시는 건드리지 않습니다.
- DeepSeek V4 가격 시간 판정은 화면에 보이는 시각 문자열 파싱 대신 해당 메시지의 `createdAt`을 사용합니다.
- DeepSeek V4 가격 인상 전 메시지는 당시 고정 요율을 사용합니다.
  - 2026-08-16 16:00 UTC 이전: Flash $0.14 / $0.0028 cache hit / $0.28 output, Pro $0.435 / $0.003625 cache hit / $0.87 output
  - 2026-08-16 16:00 UTC부터: 피크/오프피크 요율 적용
  - 2026-08-22 16:00 UTC(2026-08-23 00:00 베이징 시간)부터: 베이징 기준 토·일요일은 종일 오프피크
- RP의 모델·입력·출력·캐시 토큰 수 자체는 기존처럼 화면 표시값을 우선 사용하므로 영수증을 위해 Peek Prompt를 강제로 호출하지 않습니다.

## 메시지별 영수증

- RP 모드는 화면에 표시된 모델·입력·출력·캐시 토큰 정보를 우선 사용합니다.
- RP 화면 정보가 없을 때 `Peek Prompt`를 보완 조회할지는 설정에서 선택할 수 있으며 기본값은 꺼짐입니다.
- 대화모드는 화면에 토큰 정보가 표시되지 않으므로, 영수증 아이콘을 누른 메시지 ID로 `Peek Prompt`를 한 번 호출합니다. 기본값은 켜짐입니다.
- `Peek Prompt`는 AI 제공자에게 새 요청을 보내지 않지만 Marinara 서버에서 브라우저로 저장된 전체 프롬프트 응답을 내려받습니다.
- 환율은 저장된 값을 사용하며 사용자가 영수증 설정에서 수동 갱신할 때만 외부 요청을 보냅니다.

기존 2.x/3.x의 모델별 단가·환율 설정은 같은 확장 저장소에서 이어서 사용합니다. RP 화면 파싱을 사용하려면 Marinara의 모델명 및 토큰 사용량 표시가 켜져 있어야 합니다.

## 조회 방식 기본값

- RP 화면 정보: 켬
- RP Peek Prompt 보완: 끔
- 대화모드 Peek Prompt: 켬

각 메시지의 영수증 팝오버에서 `?` 버튼을 누르면 사용법을 다시 볼 수 있고, 톱니바퀴 버튼을 누르면 위 설정을 변경할 수 있습니다.
